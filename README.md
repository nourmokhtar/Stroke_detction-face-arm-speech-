# Stroke Detection System

A Python-based system that analyzes **facial asymmetry** and **speech patterns** to detect potential indicators of stroke. The project combines **computer vision** and **speech analysis** with a **fusion engine** for continuous risk assessment.  

⚠️ **Note:** This project is **research/educational only**. It is **not for medical diagnosis**.

---

## Features

- **Face Analysis:**  
  Detects asymmetry in facial expressions and computes a severity score.  

- **Speech Analysis:**  
  Detects deviations in speech, including patterns resembling dysarthria.  

- **Fusion Engine:**  
  Combines face and speech analysis results to produce a **continuous risk probability**.  
  - No hard thresholds — purely data-driven fusion.  
  - Provides interpretable explanations of results.  

- **CLI Interface:**  
  Run the system directly from the terminal for quick testing.
